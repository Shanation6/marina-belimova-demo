# Марина Белимова — демонстрационный личный сайт

Статический HTML/CSS/JS без сборки, сервера, кабинета, форм сбора данных и оплаты. Направления работы, подготовка, форматы встреч, FAQ и кнопки связи. Демо обозначено в подвале. Сайт «Испанский» использован как ориентир качества и не изменялся.

## Локальный запуск

В папке проекта: `python -m http.server 4187 --bind 127.0.0.1`. Откройте http://127.0.0.1:4187/. Все ресурсы локальные, пути относительные для размещения в подпапке GitHub Pages.

## Проверка и публикация

Синтаксис: `node --check assets/app.js`. Браузерная проверка: `node scripts/browser-check.mjs` с путями к установленным Playwright Core и Chromium в `PLAYWRIGHT_MODULE` и `CHROME_PATH`. Для публичного сайта задайте `SITE_URL`. Скриншоты — в игнорируемой папке `outputs`.

Публикация: `python scripts/publish.py`; состояние: `python scripts/publish.py --status`. Используется существующий доступ Git Credential Manager без записи секретов в проект.
